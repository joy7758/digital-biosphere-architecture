# Repository Map

This table summarizes the canonical repository roles for the Digital Biosphere Architecture ecosystem.

| Repository | Role in the stack | Layer | What it is not | Best entry use |
| --- | --- | --- | --- | --- |
| [digital-biosphere-architecture](https://github.com/joy7758/digital-biosphere-architecture) | narrative hub and system overview | cross-layer architecture hub | not a runtime package, not the demo, not the benchmark | start here for the canonical system explanation |
| [persona-object-protocol](https://github.com/joy7758/persona-object-protocol) | portable persona interface and projection model | Persona Layer | not the full architecture, not the audit layer, not the demo | use when you want the persona-layer entry point |
| [agent-intent-protocol](https://github.com/joy7758/agent-intent-protocol) | semantic interaction objects for intent, action, and result exchange | Interaction Layer | not a transport protocol, not a runtime framework | use when you want the interaction-layer draft |
| [token-governor](https://github.com/joy7758/token-governor) | runtime governance and trade-off control | Governance Layer | not a generic token-saving utility, not the whole stack | use when you want runtime policy and budget control context |
| [fdo-kernel-mvk](https://github.com/joy7758/fdo-kernel-mvk) | execution-integrity reference work | Execution Integrity Layer | not a separate top-level architecture axis | use when you want execution-integrity positioning inside the broader stack |
| [aro-audit](https://github.com/joy7758/aro-audit) | audit verification, export, and control-plane review | Audit Layer | not just logging, not the architecture hub, not the benchmark | use when you want post-execution review and verification surfaces |
| [agent-evidence](https://github.com/joy7758/agent-evidence) | semantic event substrate and evidence SDK | audit-adjacent substrate | not the audit control plane, not the architecture hub | use when you want capture-side evidence generation and integrations |
| [verifiable-agent-demo](https://github.com/joy7758/verifiable-agent-demo) | guided walkthrough and reference path across layers | cross-layer demo path | not a full stack product, not the normative specification for each layer | use when you want the smallest end-to-end walkthrough |
| [agent-governance-benchmark](https://github.com/joy7758/agent-governance-benchmark) | evaluation scenarios, metrics, and result sets | benchmark surface | not the canonical runtime implementation, not the architecture hub | use when you want comparative governance evaluation |
| [agent-object-protocol](https://github.com/joy7758/agent-object-protocol) | supporting protocol work for structured agent objects and interoperability artifacts | adjacent interoperability annex | not the first architecture entry point, not the narrative hub | use when you want lower-level object-contract or conformance-oriented protocol work |
