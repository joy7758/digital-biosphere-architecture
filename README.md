# Digital Biosphere Architecture

This repository is the explanation hub for a five-layer verifiable autonomous systems stack.

## Role

Digital Biosphere Architecture explains how the ecosystem fits together. It is the canonical interpretive entry point for the five-layer stack, the repository-role map, layer boundaries, terminology alignment, and long-form narrative artifacts such as the whitepaper and architecture diagrams.

## Not this repo

- not a runtime package
- not a standalone demo repo
- not a benchmark repo
- not a submission/outreach repo

## Canonical Stack

| Layer | Canonical repository | Focus |
| --- | --- | --- |
| Persona Layer | [persona-object-protocol](https://github.com/joy7758/persona-object-protocol) | persona portability and identity attachment |
| Interaction Layer | [agent-intent-protocol](https://github.com/joy7758/agent-intent-protocol) | machine-readable intent, action, and result semantics |
| Governance Layer | [token-governor](https://github.com/joy7758/token-governor) | runtime policy, budget, and permission decisions |
| Execution Integrity Layer | [fdo-kernel-mvk](https://github.com/joy7758/fdo-kernel-mvk) | replay-verifiable execution truth and integrity checks |
| Audit Layer | [aro-audit](https://github.com/joy7758/aro-audit) | audit verification, export, and control-plane review |

Supporting surfaces:

- [agent-evidence](https://github.com/joy7758/agent-evidence) is the semantic evidence substrate and SDK surface.
- [verifiable-agent-demo](https://github.com/joy7758/verifiable-agent-demo) is the smallest guided walkthrough.
- [agent-governance-benchmark](https://github.com/joy7758/agent-governance-benchmark) is the evaluation repo, not the architecture hub.
